# Arpan Biswas — Portfolio

A responsive, single-page portfolio built with semantic HTML, CSS, and vanilla JavaScript. It uses no build step or runtime dependencies.

## Run locally

Open `index.html` directly, or serve this folder with any static file server. For example:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

The page uses Google Fonts when a network connection is available and falls back to system serif and sans-serif fonts otherwise.
